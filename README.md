# نیوو کال — وب/PWA (`cal.nivoai.ir`)

اپ مستقل ردیابی کالری/رژیم، جدا از فرانت اصلی نیوو. جزئیات کامل تصمیم‌ها و معماری در
[docs/PRD-nivo-cal-standalone-app.md](../docs/PRD-nivo-cal-standalone-app.md) (ریشه‌ی مونوریپو).

نکات کلیدی:
- **API عوض نشده** — همون بک‌اند و همون endpoint های `nivo-ai-backend` (`/nivo-cal/*`, `/auth/*`).
- **لاگین کاملاً جدا** از فرانت اصلی (OTP مستقل، توکن‌های جدا در localStorage با پیشوند `nivocal_`).
- **دوزبانه** (فارسی پیش‌فرض/RTL، انگلیسی/LTR) با `react-i18next` — سوییچ از پروفایل یا صفحه‌ی ورود.
- **PWA** — قابل نصب از Safari iOS («Add to Home Screen») و از مرورگرهای اندروید.

## اجرا

```bash
npm install
cp .env.example .env   # VITE_API_URL را به بک‌اند لوکال یا استیجینگ اشاره بده
npm run dev
```

پیش‌فرض `.env` به `http://localhost:3000/api/v1` اشاره می‌کند — یعنی `nivo-ai-backend` باید لوکال روی پورت ۳۰۰۰ بالا باشد (`docker-compose up` در ریشه‌ی مونوریپو).

```bash
npm run build      # tsc + vite build → dist/
npm run preview    # پیش‌نمایش build نهایی
npm run lint        # oxlint
```

## صفحات

| مسیر | توضیح |
|---|---|
| `/login`, `/otp` | ورود با شماره موبایل + OTP (کاملاً جدا از اپ اصلی) |
| `/onboarding` | ویزارد ساخت/ویرایش پروفایل کالری (قد، وزن، سن، سطح فعالیت، هدف) |
| `/` | داشبورد — حلقه‌ی کالری باقی‌مانده، درشت‌مغذی‌ها، وعده‌های امروز، روند هفتگی |
| `/scan` | گرفتن/انتخاب عکس غذا → تحلیل هوش‌مصنوعی → نمایش نتیجه |
| `/logs` | تاریخچه‌ی وعده‌های ثبت‌شده (با امکان حذف) |
| `/weight` | ثبت وزن روزانه + روند اخیر |
| `/profile` | شماره موبایل، سوییچ زبان، ویرایش پروفایل، خروج |

## چیزهایی که عمداً هنوز نیست (وابسته به کار بک‌اند که هنوز انجام نشده)

طبق PRD، این‌ها فاز بعدی‌اند و به افزوده‌های بک‌اندی نیاز دارند که هنوز ساخته نشده‌اند:
- خرید اعتبار / طرح اختصاصی نیوو کال (بخش ۶ سند)
- بلوک تبلیغاتی (بخش ۷ سند)
- یادآوری پوش (بخش ۱۰ سند — این هم برای اپ RN طراحی شده، نه PWA)

## دیپلوی

`Dockerfile.prod` + `nginx.spa.conf` — دقیقاً همون الگوی `nivo-ai-frontend` (build چندمرحله‌ای، serve با nginx)، به‌عنوان یک اپ جدا روی همروش (مثلاً `cal-front-end`) با دامنه‌ی `cal.nivoai.ir`. برای dev لوکال هم به‌عنوان سرویس `nivo-cal-web` به `docker-compose.yml` ریشه‌ی مونوریپو اضافه شده (پورت ۵۱۸۰).

## برندینگ

لوگوهای واقعی در `public/brand/` هستند (`logo-no-background.png` برای نشان داخل اپ/`BrandMark`، `logo-white-background.png` منبع آیکون‌های PWA، `horizontal-no-background.png` برای مصارف مارکتینگ/آینده). آیکون‌های `public/pwa/*` و `public/favicon.png` از همین فایل‌ها با `scripts/gen-icons.mjs` (نیازمند `sharp`، از قبل devDependency) ساخته شده‌اند — بعد از هر تغییر لوگو دوباره اجرا کن:

```bash
node scripts/gen-icons.mjs
```

زبان پیش‌فرض همیشه فارسی است (صرف‌نظر از زبان مرورگر) — فقط با انتخاب صریح کاربر (سوییچ در پروفایل/صفحه‌ی ورود) به انگلیسی تغییر می‌کند و در `localStorage` می‌ماند.
